# Panthera Workcell v1.0.0

首个固化生产版本，发布分支为 `main`，后续现场改动先进入 `beta` 验证。

## 已包含

- `position_velocity` 生产默认模式和单一 Motion Server 固定轨迹执行。
- 两个出料口、激光修正的光谱仪放杯/取杯、倒料、毛刷清洁和原出料口返还流程。
- 常驻 Web HMI：工作站启停/重启、点位示教与热重载、工艺时间、毛刷、夹爪恢复、
  相机 RGB/深度和状态显示；页眉和浏览器图标使用 Panthera 六轴机械臂图。
- 幂等 HTTP 外部指令接口，以及传感器缺失时的固定点回退。
- 启停脚本的进程互斥、ROS CLI daemon 清理、Home 确认和失败保持上电策略。
- MIT 重力补偿兼容入口；仅用于显式调试，不是 v1.0.0 的生产默认模式。

## 固化配置

- 全零六轴 Home。
- 六轴生产上限 `2.0 rad/s`；工艺段保留局部速度/加速度配置。
- 夹爪取杯/全开目标 `0.015 m` / `0.050 m`，开合时长 `1.3675 s` / `0.9573 s`。
- 毛刷 `/dev/ttyS8`、Modbus 站号 `2`、默认 40%、清洁 `6 s`。
- 激光有效量程 `120..280 mm`，光谱仪机械基准 X `162 mm`，扫描计时 `40 s`。

## 发布验证边界

本发布执行全工作空间构建、单元测试、脚本/launch/YAML/Markdown 静态检查和 HMI 静态
资源打包检查，不为发布过程额外移动机械臂。已有实机调试记录保留在 `AGENTS.md` 和
验收文档中；外部硬急停、出料/完成信号的最终电气闭环仍按现场设备单独验收。
